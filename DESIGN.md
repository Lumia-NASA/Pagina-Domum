# MarsView design system

The brief's luxury space aesthetic is the visual authority. A quiet orbital observatory: near-black #050505, warm white #f2ede7, copper #e99c72, muted sand #a7a099. Manrope Variable is the display and UI face; IBM Plex Mono is reserved for measurements and coordinates. Local font assets avoid runtime font dependencies.

The landing surface persuades through the actual interactive globe. A centered, widely tracked MARSVIEW title leads into a lit Mars model. Fine reticles and orbit ellipses frame the subject. The first screen contains the two requested actions. Below, an asymmetric 2:1 feature composition leads to measured telemetry and a scientific footer. Equal content edges, 1200px maximum width, 24px mobile gutters, 16px card radius, pill actions.

Motion: one visible hero entrance, a pausable continuous ticker, pausable globe rotation, small button steps and card lifts. Reduced-motion stops automatic animation. No scroll-jacking. All display values distinguish demonstration, source snapshots, stale and failed fetches. All controls support keyboard focus and touch.
