# MarsView

MarsView is an independent Mars mapping and cartography project for the NASA Space Apps Challenge 2026, as supplied in the brief. The audience is challenge visitors, space enthusiasts, developers, and scientific-data explorers. The landing page should invite them to launch an interactive map and explore NASA sources.

The brief explicitly pins React, Tailwind CSS, Lucide icons, absolute near-black, diffused Martian copper and amber, uppercase spaced typography, a centered 3D globe, two named calls to action, a mission ticker, asymmetric feature cards, telemetry cards, and a minimal scientific footer. These are the visual authority; the reference video itself was not supplied.

Scope: complete local application in this workspace, no publishing requested. English interface copy follows the supplied English titles. A functional globe explorer is included; routing and weather displays are identified as demonstrations unless an actual endpoint is configured. NASA affiliation, live mission status, and a public project repository are not assumed.
